# 视觉执行规范（拆自对标爆款《你以为的庚金》）

对标视频：1920×1080 横屏，30fps，24.1s，41 个镜头，BGM 约 129 BPM（一拍 ≈ 0.464s）。

## 1. 结构

| 段落 | 时长 | 画面 | 文字 |
|---|---|---|---|
| 钩子「你以为的」 | 约 1.6–1.9s | 1 个镜头：这个天干**最日常、最小、最弱**的样子 | 「你以为的 / -X-」+ 英文副标题 + 免责 + 水印 |
| 黑屏「实际上的」 | 到 Drop 前 | 纯黑 `#000000` | 「实际上的 / -X-」逐字模糊显影，Drop 前约 0.25s 硬切消失 |
| Drop 后蒙太奇 | 到结尾 | 每个强拍一刀，按色彩段落推进，从「盛」推到「极盛」 | 只保留免责和水印 |

钩子和「实际上」必须是**同一个意象类别**的小与大，例如乙木：一盆小绿植 → 漫山花海。不要换成别的五行。

## 2. 配色与调色

- 黑位压死（暗部 5% 分位 0–10/255），高光不爆（95% 分位 180–230）。
- 饱和度明显拉高（HSV 平均 0.45–0.75）。
- ffmpeg 调色链（render.py 已内置）：`eq=contrast=1.10:saturation=1.38` + `curves=master='0/0 0.07/0 0.25/0.19 0.5/0.48 0.85/0.87 1/0.96'` + 轻锐化。
- 色彩按段落推进，每段 3–7 个镜头，同段色调一致。原片：火橙 → 钢青夜景 → 中国红 → 红墙青瓦 → 冷灰 → 雾蓝 → 冰蓝雪长城（落在金的本色）。
- 各天干的段落配色见 `tiangan_imagery.md`。

## 3. 光线

- 逆光、侧逆光为主（日出日落、透光、灯光），轮廓亮、主体暗。避免顶光平光。
- 约一半镜头加暗角，四角亮度为中心的 20–50%（`vignette=angle=PI/4` 到 `PI/5`）。航拍大场面、明亮花海可以不加。
- 不后期加光晕。

## 4. 质感

- 无颗粒、无噪点、无粒子、无漏光。
- 画面不模糊，模糊只用于文字入场。
- 干净 + 高饱和 + 高反差，好看靠素材和调色，不靠叠加。

## 5. 字幕（以 1080 高为基准）

| 层级 | 字体 | 字号 | 位置 | 样式 |
|---|---|---|---|---|
| 「你以为的 / 实际上的」 | 霞鹜文楷 Bold（LXGW WenKai，免费可商用） | 110px | 居中，top 440 | 白色；画面上加阴影 `0 2px 6px rgba(0,0,0,.6)` |
| 「-X-」 | 同上 | 110px | 居中，top 560 | 同上 |
| 英文副标题 | Playfair Display 500，全大写 | 23px，字距 0.62em | 居中，top 704 | 白色 88%，只在钩子出现 |
| 免责 | 文楷 Bold | 25px | 左上 (38, 34) | 「内容仅供娱乐参考｜无不良引导｜理性观看」，白色 86%，全程常驻 |
| 水印 | Playfair | 16px，字距 0.18em | 底部居中 top 1034 | 账号名，白色 70%，全程常驻 |

动态：
- 「你以为的」第 1 帧直接出现，和钩子画面一起硬切消失。
- 「实际上的」在黑屏第 2 帧开始，两行同时从左到右逐字显影：每字错开 2 帧，单字 8 帧内完成，水平模糊 28px→0，透明度 0→1。
- 黑屏上的字用 `#E8E8E8`，不加阴影，不出英文。

## 6. 节奏

- Drop 后平均每个镜头 1 拍。只在强拍切，弱拍不切，让上一个镜头多停一拍。
- 音乐停顿或过门处放一个 3 拍的长镜头（喘气），之后进入最后一组极盛画面。
- 100% 硬切，不用转场、闪白、缩放转场。
- 镜头内运动用素材本身的推拉摇移，冲击力来自剪辑密度。

## 7. 构图

- 大景别为主：航拍、远景、俯拍花海；穿插 1–2 个特写做节奏变化（例如花瓣带露珠），但特写不能连着用。
- 主体居中或在三分线上，天空或地面留白约 1/3。
- 标题块占画面中间约 30% 高度，中心略低于画面中心。

竖屏 1080×1920 的安全区：

| y 范围 | 用途 |
|---|---|
| 0–150px | 状态栏，空着 |
| 150–230px | 免责小字 |
| 670–1060px | 标题块（中文字号约 150px） |
| 1440px 以下 | 会被文案和按钮挡住，不放文字；水印放在 y≈1400 |
| x > 920px | 右侧按钮区，不放主体 |
