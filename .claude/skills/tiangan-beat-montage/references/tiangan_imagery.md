# 十天干意象对照表

选素材前先读这张表。整条视频的成败在于**每个镜头的主体都属于这个天干**。画面再好看，主体选错了就等于废片。

已经由用户确认过的：庚金（对标原片）、乙木（用户纠正过）。其余天干是按传统取象写的草案，第一次做某个天干时，先把下面的意象列表给用户确认，再去找素材。

---

## 乙木（阴木）—— 花草，欣欣向荣 ✅ 用户已确认

**核心意象：** 花草、藤萝、禾苗。柔软、成片、繁茂，生机勃发。「实际上的乙木」要拍出**盛大的繁荣景象**：漫山遍野的花，一望无际的草。

| 可以用 | 不能用（这是甲木或别的五行） |
|---|---|
| 花海：油菜花、薰衣草、向日葵、郁金香、杜鹃花山、格桑花、樱花海 | 参天大树、树干、仰拍树冠、森林 |
| 牡丹、芍药、荷花、兰花、菊花特写（带露珠、逆光） | 竹林、竹海（用户已否掉） |
| 紫藤花廊、蔷薇花墙、爬满花的藤架 | 榕树气根、树根、长满苔藓的树干 |
| 草原、麦浪、稻浪、翠绿的梯田禾苗 | 雨林树冠航拍、丛林 |
| 荷塘、睡莲池 | 阳光穿过森林（主体是树） |
| 花瓣飘落、花开延时 | 瀑布、云海、山峰（水和土的意象，最多做 1 个过渡镜头） |

判断方法：问自己「画面里最吸引眼球的是花或草，还是树干和树冠？」是后者就不能用。开花的树（如樱花）要拍成**满屏的花**，不能让树干成为主体。

**钩子（你以为的乙木）：** 一盆小绿植、窗台上的小花、手心浇水的嫩芽。

**色彩段落建议：**
1. 晨光嫩绿：带露珠的草叶、嫩芽逆光
2. 粉白：樱花海、桃花
3. 浓艳：牡丹、芍药、杜鹃（品红 `#C2185B`、正红）
4. 紫：薰衣草、紫藤
5. 金黄：油菜花、向日葵、麦浪
6. 翠绿：草原、稻浪梯田（3 拍长镜头）
7. 极盛收尾：漫山花海航拍、荷塘全景

## 庚金（阳金）—— 刚硬、肃杀、国之重器 ✅ 对标原片

**核心意象：** 斧钺刀剑、钢铁、重工业、国家机器、军警、大型基建。
**钩子：** 劈柴的斧头。
**原片段落：** 炼钢火光 → 化工厂夜景 → 人民大会堂、国徽 → 天安门、天坛 → 隧道施工 → 精密制造 → 港珠澳大桥 → 雪中长城（冰蓝，落在金的本色）。
