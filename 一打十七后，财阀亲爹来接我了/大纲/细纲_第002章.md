## 细纲（第 2 章）

### 第 2 章：调监控

- 核心事件：校长室里所有人等着江薇迪被开除，她只说「调监控」——画面证明对方先动手、她一直把周小满护在身后，再加一段楼道外的监控和一笔转账，陆子昂和赵婧瑶被处分，她反被表彰见义勇为，全校叫她「大姐大」；养母王秀芬打电话骂她丢人、逼她下跪道歉，被一句顶回；新手任务完成，系统奖励原主记忆里那期福星彩的头奖号码，三天后开奖。
- 字数目标：2500 字
- 属于哪段剧情：第一段剧情：楼梯间一打十七，大姐大，四千万，第二步：所有人等着她被开除，她一句话翻盘
- 目标情绪：读者先被一屋子大人压着——拍桌子的家长、劝她先道歉的辅导员、坐在角落装证人的陆子昂——憋一口气；监控一放，屋里安静，心里那口气吐出来；第二段楼道外的监控把陆子昂钉死，痛快加倍；走出行政楼全校改口，飘起来；王秀芬那通电话又把人拽回原主的十九年，她一句顶回去，解气又心酸；最后号码和倒计时亮起来，吊起「她要发财了」的期待
- 主角目标/关键选择：她要不被开除、让陆子昂和赵婧瑶为这场局付出代价。屋里每个人都在给她递台阶——「先道个歉，学校从轻处理」，接下来最省事；她不接，只要求调监控，赌的是画面；陆子昂撇清时，她把最后一次心声用在他身上，而不是留着以后保命。王秀芬逼她给赵家下跪赔不是，她选了顶回去，代价是彻底惹毛这个手里还攥着她身份证的养母
- 章首钩子：校长办公室的门一推开，一个啤酒肚男人拍着桌子：「这种学生不开除，我明天就去教育局！」——赵婧瑶她爸，赵婧瑶脸上贴着纱布坐在他旁边
- 爽点：当众翻盘加态度转变。一屋子人等她低头，她一句「调监控」，画面放完，拍桌子的家长脸白了、改口叫「小孩子打闹」；第二段监控里陆子昂在楼梯口外等了二十分钟、看了三次表，民警当场查到「辛苦费」转账；校长亲自握她的手，宣布表彰见义勇为、奖金五千；走出行政楼，走廊自动让开一条路，年级群和校园墙刷满「大姐大」

#### 这章怎么走

- 起因：一打十七之后全校广播叫她去校长室，所有人都觉得她要被开除
- 发展：校长室里赵婧瑶她爸要她赔钱退学，辅导员劝她先道歉，陆子昂咬定自己「路过劝架」；她不辩解，只要求调监控
- 转折：转角的监控放出来——汤是对方浇的、耳光是对方扇的、甩棍是对方先抡的，她从头到尾把周小满挡在身后；民警认定正当防卫、保护他人，符合见义勇为
- 高潮：陆子昂还在撇清，她用最后一次心声听见他在担心「西门那个监控」，要求调楼道外的那段——他在楼梯口外站了二十分钟、看了三次表；民警又从赵婧瑶手机里查到他转的三千四，备注「辛苦费」。陆子昂记大过，赵婧瑶记大过，其余十六人记过；校长握着她的手宣布表彰
- 结尾：傍晚王秀芬打电话来骂，被她一句顶回；偏偏宣布新手任务完成，原主记忆里那期福星彩的号码补全浮在眼前，倒计时 75 小时；她数出全部家当三十七块五

#### 分场

- 第一场：行政楼校长办公室，校长、辅导员、保卫处长、两名民警、赵婧瑶父女、陆子昂、周小满、江薇迪，约 1400 字；施压、调监控、翻盘、处分与表彰
- 第二场：行政楼走廊到 3 栋宿舍楼下，江薇迪、周小满，路过的学生，约 400 字；全校改口、「大姐大」
- 第三场：3 栋 406 阳台，江薇迪一人（偏偏在脑子里），约 700 字；王秀芬的电话、原主手腕上那道疤的来历、新手任务奖励、号码、倒计时、三十七块五
- 定调的话：她进门第一句，也是整场唯一一句要求：「调监控。」
- 定调的话：她对王秀芬：「下午我没跪，明天也不会跪。」
- 定调的话：偏偏——「新手任务完成！宿主今天没有跪任何人，偏偏奖励宿主一个会发光的东西。」

#### 情节安排（多线）

- 主线推进：改命线从「楼梯间打赢」推到「学校和警方站在她这边」，赵婧瑶和陆子昂都背上处分；她第一次在原主的世界里被公开认定「做得对」
- 辅线推进：头奖线开张：号码确认、三天倒计时到手；改命线里的养家一面露头，王秀芬被她顶回第一次，周六回家的约定下来了
- 感情线 / 关系线：无显性，但关系变化为：周小满在校长室手抖着说出「她是为了护我」，从被护的人变成替她作证的人，从这天起死心塌地；全校从不认识原主，到喊她「大姐大」

#### 人物关系和出场顺序

- 出场顺序：赵婧瑶她爸 → 赵婧瑶（纱布）→ 校长、辅导员、保卫处长、两名民警 → 陆子昂（坐在角落，像个证人）→ 周小满 → 转角监控的画面 → 心声 → 楼梯口外对着西门的监控画面 → 赵婧瑶的手机和那笔转账 → 走廊里的学生 → 年级群、校园墙 → 王秀芬（电话）→ 偏偏、新手任务奖励、号码、倒计时 → 三十七块五
- 人物关系变化：赵父对她 -70 → 不敢看她；校长 0 → 40；辅导员 -10 → 30；周小满 85 不变，但当着一屋子大人站到了她这边；陆子昂 -60 → -75；王秀芬 -70，第一次被女儿挂电话
- 视角/信息差：她知道陆子昂心里在怕楼道外的监控，屋里没人知道她怎么想到要调那一段，光环让他们往「这孩子心细」去想；陆子昂以为她只是运气好；王秀芬只知道女儿打架被叫去学校、又不知怎么得了奖；读者知道心声三次用完了，也知道号码是原主记忆里的
