## 细纲（第 5 章）

### 第 5 章：那张票，我替你守着
- 核心事件：江稚鱼戴着口罩去福彩中心匿名领奖，四千万到账；当晚去临大散打社报名练体力，社长正是投注站那个寸头男生程野，他认出了她，只说了一句「那张票，我替你守着」；她问清他奶奶的病，第二天匿名交清了手术费，回宿舍楼下撞上了高中起就欺负原主的赵婧瑶。
- 字数目标：2600 字
- 属于哪段剧情：第一段剧情：魂穿醒在食堂，躲开渣男，买下头奖，第五步：兑现四千万，程野守密
- 目标情绪：读者先在兑奖处跟着保安的白眼憋一下，再看他和中心主任改口，到账短信那一串零落下来——痛快、踏实；散打社门口被程野认出，心猛地一紧，听到「我替你守着」松下来，又带点说不清的心动；最后楼下那声拖长音的「江——稚——鱼」把人重新拽起来
- 主角目标/关键选择：她要把钱领到手、藏好，再弄清程野要什么。被认出时最省事的是给钱封口或者拿话威胁——她两样都不做，只问他想要什么；听说他奶奶的手术还差钱，她选择第二天一早自己去医院匿名交清，不让他欠她、也不拿这笔钱换他闭嘴
- 章首钩子：福彩中心门口，保安拦住穿旧外套、戴口罩的她：「小奖去投注站兑，这儿是兑大奖的。」
- 爽点：目标达成加旁人改口。保安看轻她，她把票推过去，保安愣住，中心主任亲自出来把她请进兑奖室；手机震动，银行短信「收入人民币 40,000,000.00 元」——四千万全归她；散打社里被认出后，程野不要钱、主动守密，秘密守护面板跳出「确认 1/3」，第一个知情人站到了她这边

#### 这章怎么走
- 起因：证和票都到手，她周一戴着口罩去福彩中心兑奖；手臂一用力就抖，她得去练体力
- 发展：保安看轻她，主任亲自接待，兑奖、开户、到账；她拒绝公开露面和「捐一点做宣传」的提议
- 转折：晚上她去临大体育馆地下的散打社报名，社长从擂台上翻下来——就是投注站柜台后面那个人，他的眼睛直接落到她左手腕
- 高潮：器材室门口，程野不问中没中，只说「西郊那张票，是你的」；面板跳出「确认 1/3」；她问他要什么，他说「不要。那张票，我替你守着。」
- 结尾：第二天她在市一院住院处匿名交清程奶奶的手术费；傍晚回到宿舍楼下，偏偏发布新任务，一个拖长音的声音在背后叫她的名字

#### 分场
- 第一场：临江市福彩中心兑奖处，江稚鱼、保安、中心主任，约 900 字；看轻、改口、兑奖、开户、到账
- 第二场：临大体育馆地下一层散打社，江稚鱼、程野，几个社员在背景里练，约 1100 字；被认出、确认 1/3、「我替你守着」、问出程奶奶的病
- 第三场：第二天，市一院住院处到 3 栋女生宿舍楼下，江稚鱼、住院处收费员、赵婧瑶，约 600 字；匿名交费、新任务、赵婧瑶出现
- 定调的话：保安——「小奖去投注站兑，这儿是兑大奖的。」她把票推过去：「嗯，我兑大奖。」
- 定调的话：程野——「西郊那张票，是你的。」不是问句。
- 定调的话：偏偏——「检测到第一位确认者。秘密守护·头奖：确认 1/3。偏偏提醒：这个人好凶，但头顶没有坏心思。」
- 定调的话：赵婧瑶——「哟——这不是江——稚——鱼吗？」

#### 情节安排（多线）
- 主线推进：头奖线兑现：四千万到账，存进只有她知道的账户；第一个确认者出现并主动守密
- 辅线推进：修罗场线从「程野记住了她」推到「程野守密」；改命线：偏偏发布「离开原主的命运」，赵婧瑶出现，下一段的冲突露头；美貌：C 到 B 快长好了，赵婧瑶一眼就看出她不一样
- 感情线 / 关系线：相识，往试探挪半步。程野好感从 0 到 30——不是心动，是「这姐们儿有点东西」；他守密是他自己的选择，她不收买；她替他奶奶交钱是她的选择，不告诉他。两人互相设防还在，互相欠的东西开始有了

#### 人物关系和出场顺序
- 出场顺序：福彩中心保安 → 中心主任 → 兑奖室 → 合作银行柜台 → 到账短信 → 偏偏 → 体育馆地下散打社 → 程野 → 秘密守护面板 → 程奶奶（只在程野嘴里）→ 市一院住院处 → 3 栋宿舍楼下 → 偏偏的新任务 → 赵婧瑶
- 人物关系变化：保安从看轻她 → 改口喊「女士您这边请」；程野从「记住了她的陌生人」→ 头奖秘密第一个、也是目前唯一一个确认者，主动守着；赵婧瑶从原主记忆里的噩梦 → 重新站到她面前
- 视角/信息差：兑奖处和银行经办人员按规保密，不认识她是谁，不算知情人；程野确认了她中奖，不知道金额以外的任何事（不知道系统、不知道她是魂穿）；程野不知道手术费是她交的，读者知道；赵婧瑶什么都不知道，只看见一张不一样了的脸

#### 结尾设定和钩子
- 结尾设定：钱到了，证在身上，程野守着票的事，程奶奶的手术费交了；她刚想歇口气，原主从高中起的噩梦站在宿舍楼下。没解决的：赵婧瑶要干什么、偏偏任务后面那几步是什么、程野会不会知道钱是她交的
- 章尾钩子：强。赵婧瑶拖长音「哟——这不是江——稚——鱼吗？」，头顶的 -60 在暮色里发红；原主的身体又想缩一下，她没缩，抬手把头发往耳后一拨。下一章从这场照面接
