## 二、它们写到“我们这个阶段”（第15-40章）在干什么

### 1. 八零大学生（最该学）
- 赚钱台阶：第9章赚钱计划 → 10翻译单子 → 11西餐厅 → 13投石问路 → 22-26神奇图纸、琉璃厂、墨宝斋、丰厚酬劳 → 54想摆摊 → 55确定产品 → 56心跳的轰动 → 57美而自知 → 58准备摆摊 → 59牵线搭桥 → 60开门红。
- 规律：**技能卡先到手 → 有人找上门 → 高价成交 → 旁人震惊**。一个生意线5-6章走完，开门红就收。
- 金手指发放：第3章洗髓丹、5法语、7灵田空间、8仿真机器人、33动物亲和、37高级英语、39格斗精通。**大约每4-5章一张新卡**。
- 冲突来源：家人吸血穿插在生意中间——14添了道菜、17撂挑子、34见不得妹妹好、48一百块赔偿款争议、61打屋子主意、63上门挑衅。**每5-8章一次家人找茬，当场被怼回去**。
- 美貌：第57章单开一章“美而自知”，她自己知道自己美、拿美当武器。

### 2. 绑定白富美系统
- 章名全是奖励或打脸台词：返现到账两千万、奖励兰博基尼、今日签到檀宫一号别墅、羲和斋百分百股份、五千万够吗、绿茶手段已经过时了姐姐。
- 金手指：签到 + **倍数返现**（20倍→50倍）+ 技能全能卡（驾驶、武术、游戏、计算机、法语）+ **产业所有权奖励**（商业街、医院、传媒公司、写字楼、酒店）+ **“发现可投资者”**（第25、30章，系统标出值得投的人）+ 直播专属特效（月皇排场、弯月王座）。
- 第33-41章一个完整循环：被当成买不起的人 → 买了一百套房 → “我表妹就是乡下来的” → 上两个热榜 → 这才是真正的富家千金。**身份误判→当场揭晓，3-5章一轮**。

### 3. 普女捞返系统（美貌红利照着学）
- 每一章变一个地方，章名直接写：4肤如凝脂、6完美体态Get、10冷白皮Get、15双眼皮√。
- 写法：变完立刻有人照镜子尖叫、室友追问用了什么，她心里一句“系统出品，必是精品”。**变美→旁人反应→她淡定**三拍。
- 事业线同时走：5复利投资、20接见代表团、37峰会、50奢侈品。

### 4. 女神系统（直播线照着学）
- 直播做成**赛事阶梯**：语聊PK → 新风力推 → 对手直播使坏(21) → 直播大爆(31) → 鹤立首页流量激增(32) → PK遇敌手(36) → 大哥空降榜一(37) → 系统2.0(42) → 报名年度赛(45) → 复赛 → 决赛 → 年度之星(68)。
- 每个台阶都有一个具体对手 + 一个护场的男人。
- 系统升级：第11章面板更新、42章2.0。

### 5. 学习暴富（豪门家人怎么写）
- 属性+1当章名（意志力+1、逻辑思维+1、记忆力+1），读者一眼看到“又变强了”。
- 豪门家人不撕，慢炖后悔：29迟来的关心、41她是李家的、164寿宴、177低声下气的校长。
- 第107章“你能教我赚钱吗”——别人反过来求她教赚钱。

## 三、共性：这个阶段的爆款都这么排

1. **一章一个可写进章名的爽点**（奖励、变美部位、台词、数字）。
2. **新金手指每4-5章发一张**，系统大升级每15-20章一次。
3. **生意线5-6章一个台阶**，台阶顶上必有“开门红/上热榜/年度第一”这种数字结算。
4. **生意台阶之间插家人找茬或身份误判**，当场打回去，不拖。
5. **变美单独给镜头**：部位+旁人尖叫+她淡定。
6. 女主基本不吃亏，挫折一章内翻盘。

## 四、语言风格（看了免费章节）

- **一句一段**，最多两句短句一段，手机一屏十几段。
- 白话直给，心理活动不绕：“可那咋了？她不偷不抢”这种口吻。
- 系统提示单独一段，用【叮——】开头，数字写满。
- 对话后紧跟一句反应，少比喻少形容词。
- 吐槽感强，女主心里常有一句俏皮话收尾。
