# 稚颜商业逻辑（作者 11/17 要求：读者看完学到真东西，觉得自己也能开店）

> 写稚颜相关章节前必读。所有数字是小说内设定，口径固定；不写真实品牌、真实机构；不写违规宣传、不承诺效果。
> 原则：她每一步都有讲得出来的理由，能用一两句人话说清，最好带一个数字。爽点落在「旁人以为她不懂→她一句话算清账→旁人改口」。

## 一、她为什么选这家店

- 店：临江大学城商场一楼最里头，「老周诊所」，开了八年，两百平，三间治疗室，有《医疗机构执业许可证》（医疗美容诊所），证还有四年；租约到明年三月，月租六万；设备是买断的旧光子、旧射频；老板老周五十多岁，护士长小刘跟了他八年。
- 它为什么快倒闭：老周在打价格战，光子嫩肤打五折，做一个亏一个；不会获客，靠路过的人；没有复购。每月亏七八万。倒闭的是方法，不是位置。
- 她看中的三样：
  1. 证。新开一家医疗美容诊所，要选址、装修、卫健验收、科室设置、主诊医师备案，快则半年，慢则一年多，很多人死在这一步。买一家有证的，等于买下一年时间。
  2. 位置。大学城五所大学，在校生约十二万，女生六成；商场一楼日均客流两万；旁边两栋写字楼，都是刚工作的年轻女孩。全临江爱美的人最密的地方。
  3. 便宜。转让费一百二十万，含证照主体、设备、装修。原主记忆里它三个月后被人低价盘走，后来周末排两个小时的队——说明位置没问题。
- 她的总账：盘店一百二十万，升级设备两百万，重装一百五十万，人员和流动资金三百万，再留三十万机动，总投入约八百万，全是她自己的钱。

## 二、行业头部是谁，她怎么超过它

- 头部：海城秦家的「瑰丽医美」，全国四百家连锁。
- 头部的打法：铺天盖地线上投放 → 九十九元引流卡把人骗进店 → 咨询师（按成交额拿一到两成提成）话术升单 → 卖几万的套餐和储值卡。
- 头部的弱点：
  1. 贵在获客：一个新客到店，平均要花三千到五千的投放费。
  2. 贵在提成：咨询师提成吃掉一大块利润。
  3. 没有信任：客人进门就防着被宰，复购靠推销，很少有人主动带朋友来。
- 她的打法（全部反着来）：
  1. 一张价目表：所有项目明码标价，门口、线上一个价；不设咨询师，没有成交提成；医生面诊只说适不适合，医生可以说「这个你不用做」。卖的是信任。
  2. 引流靠高频，不靠低价：皮肤管理月卡（清洁、补水、屏障修复，不打针不开刀，做完就能上课），大学生三百九十九一个月，一个月来四次。客人每周进一次店，现金流稳，还每周都见一次医生。
  3. 利润款：光电、合规注射，必须主诊医师面诊后才做。
  4. 高端款：贵太太私密预约（周太太的圈子），价格照样贴在价目表上，一视同仁。
- 账：头部一个新客三千块买来，一年来两次；她一个新客几乎不花钱，月卡客人一年来四十八次，还带室友来。同样的营收，她的利润是头部的几倍。做通一家，把「价目表＋月卡＋医生面诊＋合规手册」写成标准，就能一家一家复制，这就是连锁。
- 金句备用：「头部花三千块买一个客人，我让客人自己走进来。」「信息差能赚一次钱，信任能赚一辈子。」

## 三、门槛（她怎么一个个跨过去）

1. 证照：买有证的店，承接主体，变更负责人要报卫健审批。（第11章）
2. 主诊医师：做注射和光电必须有美容主诊医师坐诊；老周的医生年底退休，好医生都被大连锁高薪锁死。→ 引出沈既白（第13-15章）。
3. 合规：医疗广告要审批，不能承诺效果，不能拿前后对比图招揽；药械走正规渠道、批号能查。她上辈子见过太多店死在这上面，开业前先写合规手册。
4. 信任：行业最贵的成本是客人的不信任。她用价目表和直播鉴定解决。

## 四、怎么获客、怎么火

1. 她本人：S级的脸＋热搜，是全城最贵、她一分钱不花的广告。（美貌红利）
2. 种子用户：开业前招一百个「体验官」，给大学生，月卡体验，条件是写真实感受、好坏都写；店里不做效果承诺。（第12章，十分钟抢光）
3. 宿舍裂变：同宿舍四个人一起办月卡，一人免单。
4. 贵太太圈：周太太带姐妹来，价目表照贴。（第10章埋）
5. 信任事件：直播鉴定「无任何手术痕迹」，全城知道这家店的人不骗人。（第13章）
6. 复制：标准化后开第二家。（第26章）

## 五、系统规则（Lv2 事业线）

- 「白手起家」：创业的钱、团队、客户，必须是她自己挣来的。
- 依附型创业：用家族的公司、钱、人脉、名头替她做生意，算依附。惩罚：美貌立刻停止生长（卡在半成品）、偏爱光环冷却三十天、隐藏任务作废。
- 生活上的宠（大床、真丝被、直升机、副卡买衣服吃饭）不算依附，随便享。
- 隐藏任务「白手起家」：九十天内，自己的店单月流水破一百万。奖励：？？？（偏偏只透露：跟美貌有关，也跟钱有关，宝做梦都想不到）。
- Lv2 升级礼包：美貌点 8（A→S）、风口卡 1、风险扫描 3 次（一眼看出合同、账目、报价里的坑）、贵气红利（第一次见面的人默认她是最高级别的客人，服务优先）。

## 六、盘店顺利的三个金手指

1. 心声：老周对她好感过 80，她听见他真正想要的：牌子别被改成宰人的店，护士长小刘别被辞。她答应留小刘、保留老客，老周当场签。
2. 风险扫描：中介在转让合同里私加二十万「居间服务费」，被她一眼扫出，中介当场退钱道歉。
3. 贵气红利：商场物业经理一见她，主动给五年续租、免三个月租——她进店就带客流，物业算得清这笔账。

## 七、上辈子的那根刺（第10章拒绝亲爹公司时的心里话）

- 上辈子她二十八岁，给老板做医美品牌操盘，从一家店做到连锁，店是她做起来的，执照上没有她的名字，股份一分没有，年终奖被一句「公司困难」压了三年，最后累死在工位上。
- 所以这辈子她要一样东西：名字是她自己写上去的。这是她能对亲爹说出口的那一半理由；系统惩罚是说不出口的那一半。
