# 从财格：越挣扎越倒霉，躺平反而发财

开头金字：越努力越倒霉？ / 你可能是从财格（衬线黑体 + 古金渐变 + 细铜色描边，淡入微升，一道慢扫光，不弹跳、不红边）

| 段 | 画面 | 说话人 | 台词 |
|---|---|---|---|
| 1 | 沙漠里橙子大的小木芽鼓着腮帮子要扎根 → 沙子自己滑下来埋到脖子 → 沙丘上躺椅里的沙叔掀墨镜一角 | ① 小木芽 ② 沙叔 | 今天这根，我扎定了！ / 第八次了。 |
| 2 | 水妈飘来，捧脸惊叫，浇水在旁边 → 沙变泥，木芽只剩眼睛和两片叶 | ① 水妈 ② 小木芽 | 多喝水，喝了就有劲！ / 妈……我陷进去了。 |
| 3 | 沙叔从墨镜上方往下看；木芽在泥里抬头，嘴唇发抖 | ① 沙叔 ② 小木芽 | 你越使劲，我越往下塌。 / 那我咋办？ |
| 4 | 木芽摊成大字躺平 → 金沙自己像浪一样把它托上最高的沙丘 → 木芽下巴掉地 | ① 沙叔 ② 小木芽 | 躺下，别动。 / 这……就起来了？ |
| 5 | 戴小墨镜跷二郎腿的木芽；水妈抱巨型水壶赶来 → 木芽挥手 → 水妈眼珠瞪出、默默把水壶藏背后 → 金字 | 小木芽 | 妈，水先放着。 |

结尾金字：身弱无根莫硬扛，顺势从财福自长。

命理依据：木日主生在土旺之地，满盘是财（木克土为财），自身无根、又无印比可依。这种盘要“弃命从财”，顺着财走反而好；硬扎根（比劫）和多喝水（印星，水生木）都是逆势，水土相混成泥，越帮越陷。真从格很少，要看全盘，视频里不下“一定发财”的结论。

Muse 规避：全程无身体接触，沙子/水/沙浪都是环境自己动；木芽是 sprite 不是小孩，陷泥时表情是呆、平静，不哭不慌；每段 ≤2 句、过肩镜头锁说话人。
