# 新书对标：两本参考书功能位拆解（只借结构，不复刻人物剧情桥段）

来源：番茄作品页公开信息、短剧简介。正文有字体加密，未下载全书。

## A. 《没血条？你管这绝美NPC叫病弱》（大天使伽百列，番茄 7633433896964590617）
- 短剧名：《一个病秧子，我在诡异游戏当神女》（206集）
- 番茄：连载，341章，76.1万字；标签 悬疑/脑洞/穿越/无限流/灵异惊悚/游戏
- 核心梗：病弱社畜穿进诡异世界→附身自己捏的神女→能改自己面板→随手删掉血条被判「不死存在」→全服玩家脑补她是古老神国神女。她编，别人信，越编越真。
- 爽点引擎：「主角一个随意动作 → 旁人疯狂脑补 → 地位上升」。前60章章名里「脑补/震撼/偏爱/神罚」类占一半以上，基本一章一个反应链。
- 节奏：一章约2000字一个爽点；副本（小地图）约10-20章一换；每20章左右开一个新马甲/新身份，刷新新鲜感。
- 冲突收法：冲突不靠她吃苦，靠「别人质疑她 → 规则/权威当场替她站台（校长是她信徒）」。
- 万人迷：第33章「全员单箭头」——所有人单向倾慕，她不回应，修罗场靠「人人想独占」。
- 书名写法：反问句+反差（没血条？/绝美vs病弱），把核心卖点直接写进书名。
- 可借功能位：①旁人脑补链 ②权威跪迎 ③马甲分层揭晓 ④系统给评语/偏爱外化。

## B. 《我在韩国贵族高中假装财阀二代》（一树挽歌，番茄 7663152833243401278）
- 短剧名：《我海洛薇兹，在韩国贵族学院假扮千金》（两季，第二季250集）
- 番茄：已完结，179章，39.1万字，37.5万人在读；标签 现言脑洞；类韩校园 x 恶女万人迷 x 财阀 x 全洁 x 1V1 x 纯爱
- 核心梗：病危少女绑定扮演系统，伪装财阀千金入读贵族学校；每藏住一个月系统具现化奖励（豪宅豪车钱）；被揭穿则奖励清零（短剧版：被三人以上识破当场猝死）。
- 爽点引擎：「随时会掉马的倒计时 + 每月开奖」。紧张感和获得感交替。
- 节奏：月结算天然给出长线倒计时；中间靠试探/刁难/身份调查制造「暴露危机」，她每次化解都更像真千金。
- 万人迷：未婚夫（占有欲强）、纠缠型、暗中窥伺型——三种不同「危险男人」，同时也是三种拆穿她的威胁。爱慕者=猎人，这是修罗场最好用的设计。
- 简介写法：第二人称挑战句收尾（「这个挑战你是否接受」「很不高兴认识你」），角色台词式自我介绍当钩子。
- 可借功能位：①秘密+暴露倒计时 ②周期性系统奖励 ③男主兼任威胁源 ④家族秘密暗线。

## 给新书的结论
1. 每章一个「旁人反应链」爽点（震惊→改口→讨好/害怕），2000字左右一个。
2. 女主的三个秘密（系统、头奖、身世）各自对应一条暴露危机线，轮流制造紧张。
3. 男主们既是追求者也是可能拆穿她秘密的人。
4. 每卷换一次「新身份/新地图」，保持新鲜。
5. 书名把反差直接写出来，简介用女主一句狠话收尾。
