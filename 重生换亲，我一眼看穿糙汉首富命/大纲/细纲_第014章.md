## 细纲（第 14 章）

### 第 14 章：求求你姐夫呗
- 核心事件：头一个交货的集，宋青禾空着竹竿照样去集西头老地方站着，揣着那张写了七个名字的定钱纸包；订白衬衫的两个人听说「陆家媳妇买不着布了」，来要退定钱，她二话不说当场退了；过了门的宋青梅穿着新衣裳来看笑话，「求求你姐夫呗，他一句话的事」，还捎一句「娘都听说你挣钱了」；她不吵不求，当着一集人把话撂下——剩下五件，说好的半个月一天不差，到日子交不上，定钱退双份；刚退了定钱的那个媳妇又想挤回来，她说「退了就是退了，下回赶早」；夜里春花练机器，她对着空竹竿翻前世，想起上一世那年夏天县布厂把一仓库染色不匀的的确良当处理货贱卖、赵家洼的女人结伴去抢——那批布这会儿还压在仓库里没人要；她说「我要进县城，找布厂」，陆长庚把棉袄往身上一披：「我去找卫东借车。」
- 字数目标：2300 字
- 属于哪段剧情：第四段剧情：周文斌掐她布料，集上反被她当众看穿，第二步：加压——订货交不出、定钱要退、姐姐来看笑话；她不吵不求，从前世记忆里翻出县布厂的积压布
- 目标情绪：从上章「我等着看你拿啥交货」接下来，读者揪着心看她空着竹竿进集；有人来退定钱，憋屈往上涨；宋青梅那句「求求你姐夫呗」把气顶到最高；她当场退钱、撂下「退双份」，读者从憋屈转成「她有骨头」的痛快，那个想挤回来的媳妇被一句「退了就是退了」挡回去，又出一口气；夜里她对着空竹竿翻出县布厂那一仓库没人要的布，读者心里一亮——路有了；他一句「我去借车」，暖一下，盼着下一章进县城。
- 主角目标/关键选择：她要保住订货的名声，并找到一条周文斌掐不住的进布路子。关键选择：退定钱的人来了，她可以拖、可以说好话求人再等等，名声当场不至于塌；她选当场全退，还当众押上「到日子交不上，退双份」——手里五块定钱、十四块三明钱，真交不上就是十块钱的窟窿，一个集白干；押上了，剩下五个人就不走。夜里她拍板：不在乡里找布，进县城找布厂——两天来回、路费车钱都是钱，春花一个人在家看机器，走不走全看她这一个判断准不准。
- 章首钩子：集西头老地方，天刚放亮，陆长庚把摊架撑起来，竹竿上空空荡荡一件没挂；先蹲在那儿的不是买衣裳的，是订白衬衫的那个媳妇，一见她就站起来：「嫂子，听说你买不着布了？」
- 爽点：①当场退钱：两个订白衬衫的来退，她把定钱纸包当着人打开，照着名字一人一块退回去，一句软话没说，一句难听话没说；②挡回宋青梅：宋青梅说「求求你姐夫呗，他一句话的事」，她说「姐，回去告诉姐夫，布我不跟他买」，宋青梅笑她嘴硬，她转身冲排着的人把「退双份」撂下，剩下五个订货的没一个走，宋青梅脸上的笑挂不住了；③退了就是退了：刚退了定钱的那个媳妇听见「退双份」，又挤回来要重新订，她把纸包一合：「退了就是退了，下回赶早。」人堆里一片笑；④想到路子：夜里她想起县布厂那批染色不匀的的确良——乡里没人知道，供销社管不着，周文斌掐不住。

#### 这章怎么走
- 起因：上章乡供销社一尺布不卖给她，周文斌撂话「下个集我等着看你拿啥交货」；今天就是这个集，七件订货头一批该交。
- 发展：她空着竹竿照样去老地方；订白衬衫的两个人来退定钱，她当场退了；宋青梅穿着新衣裳来看笑话。
- 转折：她当着一集人撂下「到日子交不上，定钱退双份」，剩下五个人一个没走，想挤回来的被挡回去；宋青梅灰头土脸走了。
- 高潮：本章无高潮：功能是把她压到手里一尺布没有、只剩一句押上去的话，再从前世记忆里翻出一条新路。
- 结尾：夜里外屋，春花踩着机器练零头布，她盯着空竹竿翻出上一世县布厂那一仓库布，说「我要进县城，找布厂」；陆长庚把棉袄往身上一披：「我去找卫东借车。」

#### 分场
- 第一场：集西头老地方，宋青禾、陆长庚、春花、订白衬衫的两个人、来问货的人，约 700 字。空竹竿、退定钱、春花站在边上第一次跟着她赶集。
- 第二场：同一处，加宋青梅、看热闹的人，约 850 字。「求求你姐夫呗」、娘听说了、「布我不跟他买」、「退双份」、剩下五个不走、想挤回来的被挡回、宋青梅走。
- 第三场：夜里陆家外屋，宋青禾、春花、陆长庚、小满，约 750 字。春花练机器；她对着空竹竿翻前世、想起县布厂；拍板进县城；他去借车。
- 定调的话：第二场宋青梅「求求你姐夫呗，他一句话的事」。第二场她「到日子交不上，定钱退双份」「退了就是退了，下回赶早」。第三场陆长庚「我去找卫东借车」。

#### 情节安排（多线）
- 主线推进：缝纫机线从「乡里一尺不卖」压到「订货退了两件、剩下五件押着双倍定钱」，再从前世记忆里翻出县布厂这条路，拍板进县城。
- 辅线推进：金龟婿线——宋青梅替周文斌来看笑话，「求求你姐夫呗」，被挡回；换亲姑娘线——春花头一回跟她赶集，站在空摊子边上不敢吭声，夜里练机器到后半夜；娘家线一句风声：宋青梅说「娘都听说你挣钱了，挣了钱也不知道往家拿」；护妻线——他撑空摊架、夜里一句「我去借车」。
- 感情线 / 关系线：试探。他说去借车，她跟一句「车钱、油钱我出」，他「嗯」一声应下；她嘴上没再说「算我借的」，心里还是把这笔记上了。
- 事件线：乡里不卖布 → 交货的集空手 → 两个退定钱 → 她押上「退双份」稳住剩下五个 → 夜里想起县布厂积压布 → 拍板进县城，他去借车。
- 行动代价与好处归谁：退了两块定钱，押上「交不上退双份」——真交不上要赔十块；进县城两天来回要花路费、车钱，春花一个人在家。换来的是订货的人不散、名声不塌，和一条周文斌掐不住的路；拍板的是她。

#### 人物关系和出场顺序
- 出场顺序：集西头老地方、空竹竿、摊架、陆长庚、春花 → 订白衬衫的媳妇和另一个订货的 → 写着七个名字的定钱纸包 → 宋青梅、她身上的新衣裳 → 剩下五个订货的、红裙子姑娘的姐妹 → 夜里外屋、缝纫机、春花练手的零头布、空竹竿 → 上一世县布厂那一仓库染色不匀的的确良 → 陆长庚的棉袄。
- 人物关系变化：她和订货的人：七个人 → 退了两个，剩下五个押在「退双份」上，信她；她和宋青梅：第六章被说破的姐姐 → 过了门替周文斌来看笑话，又一次没占着便宜；她和陆长庚：她拍板进县城，他头一句是去借车。
- 视角/信息差：读者知道宋青梅是周文斌那边来的，集上的人只当是亲姐姐来串摊子；她记得上一世县布厂那批布今年夏天才贱卖，这会儿还压在仓库里，别人都不知道；读者不知道县布厂里有什么人、她能不能买到。

#### 结尾设定和钩子
- 结尾设定：落在院门口，陆长庚披着棉袄出了门，脚步声往村口去；外屋春花的机器还在响，她把空竹竿上的衣架一个个摘下来码好。没解决的：县布厂那批布在不在、她能不能买到、价钱多少；剩下五件押着双倍定钱，还有十天。下一章往前推的力：借车进县城，进布厂仓库。
- 章尾钩子：强。停在她那句「我要进县城，找布厂」和他披上棉袄出门的背影；下一章从进县城的车上接起。
