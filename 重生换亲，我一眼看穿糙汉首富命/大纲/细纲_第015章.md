## 细纲（第 15 章）

### 第 15 章：这批布，个人不卖
- 核心事件：天快亮，陆长庚回来了——他摸黑走到乡里，借公社值班室的电话摇到县运输站找着卫东，又走回来，一夜三十六里，裤腿湿到膝盖：卫东今天往柳河乡送化肥，后晌回空，路过乡街口。她找支书开了大队介绍信，交代春花看家，两人走到乡街口坐上卫东的回空车进了县城，在卫东家搭了一宿。第二天一早进县布厂，仓库保管员一句「这批布，个人不卖」把她挡在门口；她蹲进积压的的确良堆里一匹匹捻过去，把霉点、跳纱的真次品推到一边，挑出只是颜色一块深一块浅的好布；她看见供销科副科长冯玉兰头顶的金光朝她这边偏，绕过保管员自己上前，把这批布压到夏天是什么下场、色差做成裙子是什么样当面摆出来，四毛一尺谈成；钱不够，陆长庚说回去找卫东借，她不借，当着他拆了五块定钱的单包，买下四十五尺；冯玉兰说零买开个出门条就能提货，她坚持要盖财务章的正式发票，又在账本上记下哪天、哪个厂、哪批布、谁经手。傍晚在乡街口下客车，撞上骑车下班的周文斌，他盯着陆长庚肩上的布卷问「哪个柜台卖给你的」，她没答；他骑出去几步，车把一拐，没往家去，往乡政府那条街去了。
- 字数目标：2300 字
- 属于哪段剧情：第四段剧情：周文斌掐她布料，集上反被她当众看穿，第三步：尝试——进县城，在布厂仓库捻出好布，自己争取那个能帮她的人，谈价、要发票
- 目标情绪：从上章「路有了」那点亮光接下来，天亮看见他裤腿湿到膝盖，心里一暖；进了布厂被一句「个人不卖」挡在仓库门口，心又悬起来——这条路全凭上辈子隔着院墙看的那一眼，可能白跑；她蹲进布堆里一匹匹捻，把保管员嘴里的「次品」分出好坏，读者等着她亮眼力；冯玉兰被她说动、四毛一尺拍板，憋了两章的气第一次吐出来——布到手了，比乡里处理布一尺还便宜两毛、不要布票，周文斌的柜台一尺没沾；拆定钱那一下心又揪一下；她坚持要发票、把来路记进账本，读者看见她手里攥住了一张牌；最后周文斌盯着布卷、车把拐向乡政府，读者知道麻烦要来，也知道她怀里揣着那张发票，盼着下一集。
- 主角目标/关键选择：她要买到够交五件订货、还能再做一批新货的布，而且来路要清清楚楚。关键选择有三处：①保管员把门挡死，她可以等夏天厂门市清仓、也可以塞好话托保管员通融，她看准冯玉兰头顶偏向她的金光，自己上前去争；②钱只够三十来尺——明钱十四块三，扣下回程两张车票一块二，剩十三块一——够交五件订货，剩不下几件新货；陆长庚说回去找卫东先借，她不借，当着他把五块定钱的单包拆了，全押进去买下四十五尺；定钱是订货人的钱，这批布要是做砸了、卖不动，到第五十四天她连退双份的十块都拿不出；③冯玉兰说零买开个出门条就能提货，她坚持要盖章的正式发票，在财务室门口多等了半个钟头，回程客车差点没赶上。
- 章首钩子：天快亮，院门吱呀一响，陆长庚回来了，棉袄上一层露水，裤腿湿到膝盖，进门头一句：「卫东今儿后晌回空，路过乡街口。」她这才明白，他这一夜是走到乡里又走回来的。
- 爽点：①认布：保管员说「一仓库都是次品，个人不卖」，她蹲下去一匹匹捻，对着仓库门口的光看经纬，把带霉点、跳纱的推到一边，剩下的拍一拍：「这几匹不是次品，就是颜色没染匀。布身比供销社柜上的还好。」保管员不服，拿过一匹自己捻了捻，没吭声；②争下贵人：她把一匹浅蓝的当着冯玉兰折起来，深的那截压到底下——「做成裙子，深的在下摆，人家只当是故意染的」，冯玉兰笑了，四毛一尺拍板；③收获盘点：四十五尺不要布票的的确良到手，十八块；照乡里处理布六毛一尺算要二十七块，省下九块，周文斌的柜台一尺没沾；④要发票：冯玉兰看她把盖了章的发票折好、在账本上一笔一笔记来路，说「你比我们科里的人还讲究」，临走撂一句：「这批布还有，你卖得动，再来找我。」

#### 这章怎么走
- 起因：乡里一尺布不卖给她，剩五件订货押着退双份，还剩十天两个集；她想起上一世县布厂开春积压、夏天才贱卖的那批的确良，拍板进县城；陆长庚连夜去找车。
- 发展：卫东的回空车把两人捎进县城；第二天进布厂，保管员说这批布个人不卖；她蹲进布堆里一匹匹捻，分出真次品和只是颜色不匀的好布。
- 转折：冯玉兰进了仓库，她看见冯玉兰头顶金光朝她这边偏，绕过保管员上前去谈；冯玉兰要五毛，她摆出布压到夏天的下场和色差的用法，谈到四毛。
- 高潮：钱不够，陆长庚说去借，她不借，当着他拆开定钱单包，全押上买下四十五尺；冯玉兰说开个出门条就行，她说要发票，盖章的。
- 结尾：傍晚乡街口，周文斌骑车停在她跟前盯着布卷问哪个柜台卖的，她没答，揣着发票的那只手按在怀里；他骑出去几步，车把一拐，往乡政府那条街去了。

#### 分场
- 第一场：天亮的陆家到乡街口、卫东的解放卡车上，宋青禾、陆长庚、春花、小满、支书（一笔）、卫东，约 450 字。他走了一夜；介绍信；交代春花；回空车，卫东不收油钱，她说给他闺女做件褂子。
- 第二场：县布厂仓库，宋青禾、陆长庚、仓库保管员，约 800 字。门卫看介绍信放进；「这批布，个人不卖」；她蹲进布堆一匹匹捻，分出好坏，保管员不服又不吭声。
- 第三场：同一仓库到供销科、财务室门口，加冯玉兰，约 750 字。看见金光偏向她；她上前谈价，四毛拍板；钱不够，拆定钱；要发票、记账本；冯玉兰那句「再来找我」。
- 第四场：回程客车到乡街口，宋青禾、陆长庚、周文斌，约 300 字。车顶上捆的布卷；下车撞上周文斌；他问、她不答；他拐向乡政府。
- 定调的话：第二场保管员「这批布，个人不卖」。第三场她「做成裙子，深的在下摆，人家只当是故意染的」「要发票，盖章的」。第三场冯玉兰「这批布还有，你卖得动，再来找我」。第四场周文斌「哪个柜台卖给你的？」

#### 情节安排（多线）
- 主线推进：缝纫机线从「乡里一尺不卖、手里一尺布没有」推到四十五尺布到手、够交五件订货还能再做一批新货，县布厂这条周文斌掐不住的路打通了一半——认得了一个能说上话的人，手里有发票。
- 辅线推进：金龟婿线——周文斌在乡街口撞见她扛布回来，问来路没问着，车把拐向乡政府，引出下一章他领人来；换亲姑娘线——她走前交代春花两天里把零头布上的直线走匀、学着上裙腰，春花头一回一个人看家看机器；护妻线——他一夜走三十六里找车，进城后扛布、站在她身后，钱不够时说去借，被她拦下。
- 感情线 / 关系线：试探。他走了一夜没提一个字，她看见湿到膝盖的裤腿，没说谢，把灶上温着的那碗糊糊推给他；钱不够时他说「我去跟卫东借」，她说「不借」，当着他拆了定钱——她还是不肯多欠他一分，他看了她一眼，没再劝，把四十五尺布扛上了肩。
- 事件线：连夜借电话找车 → 支书开介绍信 → 回空车进城 → 布厂个人不卖 → 捻布分出好坏 → 争到冯玉兰、四毛一尺 → 钱不够拆定钱 → 盖章发票、记账本 → 客车回乡，撞上周文斌 → 他拐向乡政府。
- 行动代价与好处归谁：代价是拆了五块定钱、兜里只剩一毛，这批布做砸了连退双份都拿不出；陆长庚一夜走了三十六里；为等发票差点误了客车。好处归她：四十五尺布、一张盖章的发票、一个往后能说上话的人，都落在她名下；卫东的车是陆长庚的人情，她许下给卫东闺女做件褂子。

#### 人物关系和出场顺序
- 出场顺序：院门、陆长庚湿透的裤腿 → 支书孙守田和大队介绍信 → 春花、小满、缝纫机 → 乡街口、郑卫东的解放卡车 → 县布厂门卫 → 仓库、积压的的确良、仓库保管员 → 冯玉兰和她头顶的金光 → 五块定钱的单包 → 财务室、盖章的发票、账本 → 县汽车站的客车、车顶上的布卷 → 乡街口、骑自行车的周文斌 → 乡政府那条街。
- 人物关系变化：她和冯玉兰：素不相识 → 被她的眼力说动，四毛卖给她，留下一句「再来找我」；她和仓库保管员：挡她的人 → 不服又说不出话；她和卫东：叫嫂子的战友 → 捎了车、不收油钱，欠下一件褂子的人情；她和陆长庚：他一夜走了三十六里，她不肯借他的人情，他由着她；她和周文斌：在乡街口又撞上，他看见她手里有布、不知道哪来的。
- 视角/信息差：读者和她知道布是县布厂的、有盖章的发票和大队介绍信；周文斌只看见一卷颜色深一块浅一块的处理布，问不出来路，认定她来路不明；她看见冯玉兰的金光偏向她，冯玉兰只当遇上一个眼毒的乡下媳妇；读者看见周文斌拐向乡政府那条街，她也看见了，可不知道他去干什么；她心里有数四毛这个价夏天就是厂门市的价，冯玉兰不知道她是怎么知道的。

#### 结尾设定和钩子
- 结尾设定：落在乡街口，她站住回头，看着周文斌的自行车拐进乡政府那条街；陆长庚肩上的布卷往上颠了颠，她的手还按在怀里那张发票上。没解决的：周文斌去乡政府干什么；五件订货加一批新货要在十天里做出来；定钱拆了，兜里只剩一毛。下一章往前推的力：连夜赶工、用这批深一块浅一块的布做出新款上集。
- 章尾钩子：中强。停在周文斌车把一拐、往乡政府那条街去的背影和他头顶往下一沉的黑气；下一章从回家连夜铺开这四十五尺布接起。
