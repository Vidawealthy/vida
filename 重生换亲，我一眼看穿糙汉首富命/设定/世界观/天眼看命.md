# 天眼看命

## 怎么来的
宋青禾上一世死在赵家井边，再睁眼回到换亲那天早上，眼睛就能看见人头顶的气运。来由不解释、不追究，全书不揭秘（不是要后面揭开的谜）。

## 看见什么（颜色和光，漫剧直接画）
| 颜色/光 | 代表什么 | 例 |
|--------|---------|----|
| 金光 | 富贵命、财运；越亮越厚，命越大 | 陆长庚头顶金光冲天 |
| 红光 | 喜事、姻缘、贵人缘 | 要办喜事的人家头顶泛红 |
| 青白（淡淡的清气） | 平常人、平安无事 | 大多数村里人 |
| 灰气 | 病气、霉运、身子虚 | 陆小满头顶一层灰 |
| 黑气（印堂发黑） | 灾祸临头；黑气越重、越往下压，祸越近越大 | 周文斌金光底下缠着黑气 |
| 血光 | 血光之灾，或手上沾过人命 | 赵铁柱头顶一片血红 |
| 黑线 | 横在命里的一道劫，不应验就一直在 | 陆长庚金光中间那道细黑线 |

- 光会闪：一闪一闪说明祸事就在这几天应验。
- 颜色会当场变：人做了选择、事情改了走向，头顶颜色跟着变——换亲那一刻陆长庚的金光又亮一截，宋青梅头顶的红光转灰。这是全书「命是选出来的」的直观表现，每次变色都是一个爽点镜头。

## 用在做生意上（全书主要用法）
- 看人：合伙人、买家、供货的头顶金光是真有本事和财路，黑气是要坑人或自己要出事；挑女工看灰气（病）、看心正不正（清气还是浊气）。
- 看事：一批货、一笔买卖经手人的头顶发黑、黑气发闪，就是这笔货要出事；黑气往哪个人身上飘，祸就从哪个人那来。
- 看贵人：头顶带红光、金光且朝她这边偏的人，是能帮她一把的贵人（下订单的、批执照的），她要自己去争取，不是贵人自己送上门。
- 每个剧情单元换着用：换对象（合伙人/工人/买家/对家）、换场面（谈价/进货/招工/查账）、换解法（躲开/拆穿/反将一军），不重复同一招。

## 陆长庚的金光与黑线（作者真相，尾声才揭开）
- 她和读者看到的：陆长庚头顶金光冲天，她认定是「首富命」；中间横一道细黑线，她认定是前世他蹲大牢那一劫。
- 真相：那金光是「首富之夫」的命——他的富贵连在妻子身上，妻子是首富他才是金光。前世他没娶她，金光一直没应验，还被周文斌举报蹲了牢。那道黑线也不是他自己的劫，是她的生意要遭的劫映在他头上（他的命和她绑着，她看不见自己，就只能从他头上看见）。
- 公平线索（写正文时埋）：他的金光从不在他自己干成什么事时变亮，只在她的生意上台阶时变亮——换亲那一刻、成衣铺开张、县城店爆单、建厂。她每次都以为是「旺夫」，读者回头能对上。
- 第 2 卷周文斌设局时，她明白黑线是冲她生意来的（揭一半）；尾声看见金光那根连回她自己的线，才明白「首富之夫」（全揭）。

## 看不见什么（硬规矩，全书不破）
- 看不见自己的命。照镜子、照水，头顶什么都没有。
- 只看见「是什么」，看不见「为什么」「怎么办」：她看到黑气，得自己推出祸从哪来、该怎么破——靠前世记忆、靠真的八字五行知识（生辰八字、五行生克、面相）、靠察言观色。天眼不替她做决定。
- 前世记忆只到她死的那年（换亲后两年多），再往后的事她不知道，只能靠天眼看。
- 天眼不外传、不被任何人确证；旁人最多说她「眼毒」「会看人」。

## 八字五行托底
- 看命时她会顺口说出对方的生辰八字和五行喜忌，作为对外的说法（外人以为她会算命，不知道她是「看见的」）。
- 八字五行知识用真实的说法，不编；每次只用一两句，点到为止，不讲课。
- 年代里算命是「封建迷信」，当众算命有风险：她对外多说「看面相」「我看人准」，必要时借八字的说法，不公开摆摊。

## 成长（四阶段）
1. 基础（第 1 卷）：只能看颜色和明暗。
2. 发展（第 1 卷末-第 2 卷）：盯着看久了，能看到黑气、灰气往哪边飘——祸是从哪个人、哪个方向来的（看出哪批布、哪个经手人要出事）。
3. 成熟（第 2 卷高潮）：能看清黑线什么时候应验（光闪的快慢对上日子），用来卡准周文斌举报的时辰，一起破局。
4. 到顶（第 3 卷）：能看见两个人的气运缠在一起——谁在害谁、谁和谁绑着命（用于揭开娘、姐姐和赵家合谋的前世真相、收拾周文斌）；尾声用这一档看见陆长庚的金光连回她自己。到顶后仍看不见她自己头顶的命。

## 上限和代价：祸不消失，谁害人谁接祸
- 看命不限次数，没有身体代价。
- 规矩是「改了别人的命，那份祸不会凭空消失」：她救下的人身上的黑气，会换个形状落到害人的人头上。谁存心害人，祸最后就落回谁身上——这是全书现世报的来源，每次救人都连着一次打脸，漫剧里画成黑气从受害人头顶飘走、缠上害人者。
- 她只能「看见」和「破局」，不能直接把祸往别人身上推：得她自己拆穿、躲开或反将一军，祸才会转走；她什么都不做，祸就照原样应验。
