# 周文斌

```text
姓名：周文斌
性别：男
角色功能：头号宿敌；书名里那个「金龟婿」，命里败家；上一世诬告陆长庚入狱的人。
与主角关系：原本是宋青禾的未婚夫，被宋青梅抢走后成了姐夫。
核心特质：外头斯文体面、心里阴毒小气；嫉妒心重，见不得别人比他强。
标志性特征：上衣口袋永远别着一支钢笔（其实不怎么写字），头发抹得锃亮；说话爱带「我们单位」。
退场方式：第 3 卷——诬告、赌账、私下倒腾公家东西的烂账被一起翻出来，当众被带走。
```

## 反派层级
大弧 Boss（第 2-3 卷的核心矛盾）。

## 天眼里
金光底下缠着黑气——金光是他爹挣下的家底和铁饭碗，黑气是他自己命里的败家；越往后黑气越压过金光。

## 建立四要素
1. 实力展示：公社/供销社干部家的儿子，自己在供销社有正式工作，认识公社、县里管事的人；一句话就能卡陆长庚的货、让收购站不收。
2. 动机可信：他从小被夸是「公社最有出息的后生」，看不得一个赶车的穷汉越过越好、看不得被他「挑剩下」的女人过得比他媳妇好；加上自己赌钱欠账，需要钱，眼红陆家的买卖。
3. 真实威胁：第 2 卷他赢一局——卡了陆家的货、让陆长庚被带去问话，家里一度断了进项；这是全书女主最难的一段（压得住但不长虐，三四章内翻回来）。
4. 终极意图：他要的不只是钱，是把陆长庚送进去、把陆家买卖吞到自己手里；这个意图在第 2 卷高潮才亮出来。

## 性格四步
- 自己的目标：在他眼里自己是体面人，要保住「周家体面」和单位里的位置。
- 过往成因：他爹在单位压了他半辈子，他最怕的就是被人看不起、落到泥里。
- 依仗变死穴：他最信「举报信」和「关系」这一招，上一世靠它赢过；这一世宋青禾就是让他的举报信变成他自己的罪证。
- 与女主对照：他靠关系和算计吃别人，她靠看准和实干挣自己的。

## 怎么败（三步，配合周家的「败家命」）
1. 第 1 卷：小人使绊子，被女主当众看穿打回去，第一次丢脸。
2. 第 2 卷：举报设局失败，局反咬到他自己身上，丢了工作、周家开始败。
3. 第 3 卷：赌账和旧事一起炸，他被带走，周家彻底倒。
