# 宋青梅

```text
姓名：宋青梅
性别：女
角色功能：女主亲姐，抢婚的人；全书最长的一条「对照组」，宋青禾选对一次、挣一笔，她就败一截；前世害死妹妹的主意是她出的。
与主角关系：亲姐妹，从小抢妹妹的东西；娘的心头肉。
核心特质：好面子、爱比、眼皮子浅；会在爹娘面前装乖哭。
标志性特征：全村最俊的姑娘，爱扎红头绳、穿最新的花布衫——后来她穿的时兴衣裳，全是妹妹店里出的；一着急就掐自己手心挤眼泪。
退场方式：第 3 卷——周家败光、离婚回娘家，娘家也嫌她；当众认下前世给娘出主意、把妹妹换进赵家后，在全村人的唾沫里收场（不死、不疯，就是一辈子抬不起头）。
```

## 反派层级
中等反派（女主私人恩怨的主对手，贯穿三卷，每卷败一截）。

## 动机（从她的视角说得通）
- 她要保住的东西：「我比妹妹强」。从小她是爹娘眼里有出息的那个，妹妹是干活的；她要嫁得最好，要一辈子压妹妹一头。
- 过往成因：娘从小跟她说「你长得俊，你得嫁城里人，你妹就是给家里换东西的」，她信了一辈子。
- 依仗变死穴：她只认看得见的体面（铁饭碗、彩礼、穿戴），所以抢了周文斌；也因为只看表面，一次次被周家的空架子坑。
- 与女主对照：她看人看「家底」，妹妹看人看「命」；她靠嫁人想过好日子，妹妹靠自己挣；她抢来的都在败，妹妹挑的、挣的都在旺。

## 前世真相里的她（作者真相，第 3 卷揭开）
上一世换亲前，是她跟娘出的主意：自己去抢周文斌，把妹妹换进赵家给哥哥换媳妇；她听说过赵铁柱打死前妻的事，还说「二丫皮实，打不死」。

## 三步败落
1. 第 1 卷：风光嫁进周家，回门时炫耀，嘲笑妹妹嫁穷汉、摆地摊丢人；婚后发现周家欠着账、周文斌赌钱，开始眼红妹妹。
2. 第 2 卷：撺掇周文斌对付妹妹的生意，又想「换回来」——在村里散谣言、去陆家献殷勤，被陆长庚当众撅回去。
3. 第 3 卷：周家倒了，她走投无路，想拿姐妹情、拿娘家逼妹妹分钱、进厂当管事；前世真相揭开，她出过的主意被当众认下。
