# 王桂芬

```text
姓名：王桂芬
性别：女
角色功能：女主的娘，吸血娘家的头；全书「极品家人」的总代表；前世把女主换进赵家的人。
与主角关系：亲娘。
核心特质：偏心到骨子里、嘴碎、拿孝道压人。
标志性特征：一张嘴就是「我生你养你」；一着急就往地上一坐拍大腿嚎。
退场方式：第 3 卷——前世真相被当众揭开，她收赵家钱、明知赵家打死过人还送闺女过去的事全村都知道了；儿子娶不上媳妇，大闺女离婚回家，老了没人管（不写死，写她被戳脊梁骨过日子）。
```

## 反派层级
小反派升级到中等反派：第 1 卷是开局的直接压迫者，之后每卷闺女的生意上一个台阶，她就上门要钱、要人一次（要分钱、要给儿子在店里安排活、要把宋耀祖塞进厂当官），每次被打回去更狠一档。

## 动机（从她的视角说得通）
- 她要保住的：儿子宋耀祖娶上媳妇、宋家有后。闺女是「泼出去的水」，能换东西就该换；闺女挣了钱，也该是娘家的。
- 过往成因：她自己当年就是被娘家换亲换过来的，吃了一辈子苦，觉得「女人都是这么过来的」——她是女主若认命会变成的样子，也是厂里那些姑娘的娘的样子。
- 依仗变死穴：她只会一招「孝道」压人；女主断亲立了字据、有大队见证，这一招就不灵了。

## 前世真相里的她（作者真相，第 3 卷揭开）
上一世她早知道赵铁柱打死过前妻，收了赵家的钱和一个闺女，照样把二丫头换过去；女主死前那天，她还上门要钱。

## 宋家其他人（只给一行，出细纲时再补）
- 宋老栓：女主的爹，窝囊、怕老婆，关键时刻一声不吭——他的沉默本身就是帮凶。
- 宋耀祖：女主的哥哥，二十四五娶不上媳妇，好吃懒做，被娘惯坏；换亲黄了后恨妹妹。
